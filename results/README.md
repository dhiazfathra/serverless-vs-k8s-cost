# results/

Raw harness output, committed. Every number in `summary.md` and in the write-up
comes from a file in here.

- `summary.md` — generated by `scripts/summarize.py`. The measured resource
  table is the primary result; the dollar tables are a derived view of it.
- `raw/sweep_<arm>_d<duty>_rep<n>.json` — one measurement cell: the folded
  record (`scripts/cell.py`) that the gate admitted.
- `raw/sweep_<arm>_d<duty>_rep<n>.d/` — that cell's per-burst artefacts before
  folding: `<i>.k6.json` (the open-loop load report), `<i>.stats.json` (the
  server's own resource meter), `<i>.cold.json` (the measured cold start), and
  `meta.json` (the sweep parameters the gate grades against).
- `raw/calib.json` — the calibration cell on the **baseline** arm. The whole run
  aborts if the always-on arm cannot hold the offered rate, because every dollar
  delta in the matrix is measured against it.
- `raw/idle_calibration.json` — what the container consumes doing nothing.
- `raw/<cell>.d/REFUSED.json` — a cell the gate rejected. Kept deliberately: a
  refusal is evidence, and a gate whose refusals are deleted is unfalsifiable.
- `.progress` — run state for `scripts/heartbeat.sh status`. Gitignored; it is
  not a result.

Commands used are in the repo README under "Rerun it".

**No dollar figure in here was billed by anyone.** Cost is modelled from the
measured resources by `scripts/cost.py` using the constants in `pricing.json`.
